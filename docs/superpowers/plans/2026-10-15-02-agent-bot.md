# Agent, Voice and Telegram Bot Implementation Plan (Plan 2 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working Telegram bot: members write or speak "кофе 350" and an LLM agent with tool calling performs CRUD on their own expenses; the whole backend runs with `docker compose up`.

**Architecture:** `internal/llm` is a provider-agnostic chat client (OpenAI-compatible HTTP, OpenRouter by default). `internal/agent` runs a bounded tool-calling loop over five tools that wrap `expense.Service` with `expense.Own(userID)` — the user id is injected from the Telegram update and never appears in tool schemas. `internal/stt` transcribes voice via OpenRouter. `internal/bot` gates members, shows typing, routes text/voice to the agent; a thin adapter binds it to `go-telegram/bot`. `cmd/server` wires everything.

**Tech Stack:** Go 1.26, go-telegram/bot v1.27.0, golang.org/x/sync/errgroup, OpenRouter (chat completions + `/audio/transcriptions`), Docker (distroless), Postgres 16.

**Spec:** `docs/superpowers/specs/2026-10-15-family-expenses-design.md` (sections 4, 6, 7, 10, 11). Requires Plan 1 (`2026-10-15-01-backend-core.md`) completed.

## Global Constraints

- Go module `github.com/TheLastManStandin/TestForSemen/backend`, `go 1.26`; pinned deps from the overview; add `github.com/go-telegram/bot v1.27.0` and `golang.org/x/sync` (latest).
- Agent tool JSON schemas never contain `user_id`; tools always call the service with `expense.Own(userID)`.
- Agent loop: at most 6 LLM iterations per message; history = last 20 messages not older than 6 hours; LLM timeout per attempt from `LLM_TIMEOUT` (30s); 2 retries with exponential backoff on 429/5xx.
- Periods are resolved by Go (`domain.ResolvePeriod`), not the model.
- Bot replies: plain text (no parse mode), Russian, money as `"1 200 ₽"`, max 4096 characters.
- Non-members get a refusal with their Telegram ID; the LLM is never called for them.
- Voice: OpenRouter `POST {LLM_BASE_URL}/audio/transcriptions`, JSON `{model, input_audio: {data: base64, format: "ogg"}, language: "ru"}`; reject voice longer than `STT_MAX_SECONDS`; reply starts with `🎤 «<transcript>»`.
- Conventional Commits, no attribution trailers. Integration tests skip with `-short`.

## Review Focus

1. **Model sends numbers where strings are expected (or the reverse)** — `"amount": 350`, `"id": "42"`. Expected: accepted. Pinned by `TestAddExpenseAcceptsNumericAmount` and `TestUpdateExpenseAcceptsStringID` (Task 2).
2. **History window cuts a turn in half** — the oldest kept message is a `tool` result without its assistant call; providers reject that with 400. Expected: history starts at the first `user` message. Pinned by `TestRunHistoryStartsAtUserMessage` (Task 4).
3. **Two messages from one member arrive at once** — concurrent runs would interleave history. Expected: runs for one member are serialized. Pinned by `TestRunSerializesPerUser` (Task 4).
4. **Very long agent reply** (e.g. listing 50 expenses) — Telegram rejects >4096 chars. Expected: truncated with "…". Pinned by `TestLongReplyIsTruncated` (Task 6).
5. **Telegram sends `/start` as the first message** — not an expense. Expected: greeting, no LLM call. Pinned by `TestStartCommandGreets` (Task 6).

// Package llm is a minimal provider-agnostic chat-completions client with tool calling.
package llm

import (
	"context"
	"encoding/json"
	"fmt"
)

// Role of a chat message.
type Role string

const (
	RoleSystem    Role = "system"
	RoleUser      Role = "user"
	RoleAssistant Role = "assistant"
	RoleTool      Role = "tool"
)

// Message uses the chat-completions wire format, so it can be stored and replayed as-is.
type Message struct {
	Role       Role       `json:"role"`
	Content    string     `json:"content"`
	ToolCalls  []ToolCall `json:"tool_calls,omitempty"`
	ToolCallID string     `json:"tool_call_id,omitempty"`
}

type ToolCall struct {
	ID       string       `json:"id"`
	Type     string       `json:"type"`
	Function FunctionCall `json:"function"`
}

type FunctionCall struct {
	Name      string `json:"name"`
	Arguments string `json:"arguments"` // JSON object encoded as a string
}

type Tool struct {
	Type     string      `json:"type"`
	Function FunctionDef `json:"function"`
}

type FunctionDef struct {
	Name        string          `json:"name"`
	Description string          `json:"description"`
	Parameters  json.RawMessage `json:"parameters"` // JSON Schema
}

type ChatRequest struct {
	Model       string
	Messages    []Message
	Tools       []Tool
	Temperature *float64
}

type Usage struct {
	PromptTokens     int     `json:"prompt_tokens"`
	CompletionTokens int     `json:"completion_tokens"`
	Cost             float64 `json:"cost,omitempty"` // USD, when the provider reports it (OpenRouter)
}

// Add accumulates o into u.
func (u *Usage) Add(o Usage) {
	u.PromptTokens += o.PromptTokens
	u.CompletionTokens += o.CompletionTokens
	u.Cost += o.Cost
}

type ChatResponse struct {
	Message Message
	Usage   Usage
}

// Client sends one chat-completions request.
type Client interface {
	Chat(ctx context.Context, req ChatRequest) (ChatResponse, error)
}

// APIError is an error reported by the provider (HTTP status or in-body error).
type APIError struct {
	Status  int
	Message string
}

func (e *APIError) Error() string { return fmt.Sprintf("llm api error %d: %s", e.Status, e.Message) }
```

package llm

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"net/http"
	"strconv"
	"strings"
	"time"
)

// OpenAIConfig configures an OpenAI-compatible endpoint (OpenRouter, OpenAI, Ollama, vLLM…).
type OpenAIConfig struct {
	BaseURL    string // e.g. https://openrouter.ai/api/v1
	APIKey     string
	Timeout    time.Duration // per attempt; default 30s
	MaxRetries int           // extra attempts on 429/5xx/network errors
	RetryBase  time.Duration // first backoff delay, doubled each retry; default 500ms
	HTTPClient *http.Client
	Referer    string // optional OpenRouter attribution headers
	Title      string
}

// OpenAI implements Client over HTTP.
type OpenAI struct {
	cfg  OpenAIConfig
	http *http.Client
}

// NewOpenAI returns a client with defaults applied.
func NewOpenAI(cfg OpenAIConfig) *OpenAI {
	if cfg.Timeout == 0 {
		cfg.Timeout = 30 * time.Second
	}
	if cfg.RetryBase == 0 {
		cfg.RetryBase = 500 * time.Millisecond
	}
	hc := cfg.HTTPClient
	if hc == nil {
		hc = &http.Client{}
	}
	return &OpenAI{cfg: cfg, http: hc}
}

type chatPayload struct {
	Model       string    `json:"model"`
	Messages    []Message `json:"messages"`
	Tools       []Tool    `json:"tools,omitempty"`
	ToolChoice  string    `json:"tool_choice,omitempty"`
	Temperature *float64  `json:"temperature,omitempty"`
}

type chatResult struct {
	Choices []struct {
		Message Message `json:"message"`
	} `json:"choices"`
	Usage Usage `json:"usage"`
	Error *struct {
		Message string          `json:"message"`
		Code    json.RawMessage `json:"code"`
	} `json:"error"`
}

func (c *OpenAI) Chat(ctx context.Context, req ChatRequest) (ChatResponse, error) {
	p := chatPayload{Model: req.Model, Messages: req.Messages, Tools: req.Tools, Temperature: req.Temperature}
	if len(req.Tools) > 0 {
		p.ToolChoice = "auto"
	}
	body, err := json.Marshal(p)
	if err != nil {
		return ChatResponse{}, fmt.Errorf("marshal request: %w", err)
	}

	var lastErr error
	for attempt := 0; attempt <= c.cfg.MaxRetries; attempt++ {
		if attempt > 0 {
			select {
			case <-ctx.Done():
				return ChatResponse{}, ctx.Err()
			case <-time.After(c.cfg.RetryBase << (attempt - 1)):
			}
		}
		resp, err := c.once(ctx, body)
		if err == nil {
			return resp, nil
		}
		lastErr = err
		if ctx.Err() != nil || !retryable(err) {
			break
		}
	}
	return ChatResponse{}, lastErr
}

func (c *OpenAI) once(ctx context.Context, body []byte) (ChatResponse, error) {
	ctx, cancel := context.WithTimeout(ctx, c.cfg.Timeout)
	defer cancel()

	req, err := http.NewRequestWithContext(ctx, http.MethodPost, strings.TrimRight(c.cfg.BaseURL, "/")+"/chat/completions", bytes.NewReader(body))
	if err != nil {
		return ChatResponse{}, err
	}
	req.Header.Set("Authorization", "Bearer "+c.cfg.APIKey)
	req.Header.Set("Content-Type", "application/json")
	if c.cfg.Referer != "" {
		req.Header.Set("HTTP-Referer", c.cfg.Referer)
	}
	if c.cfg.Title != "" {
		req.Header.Set("X-Title", c.cfg.Title)
	}

	resp, err := c.http.Do(req)
	if err != nil {
		return ChatResponse{}, fmt.Errorf("llm request: %w", err)
	}
	defer resp.Body.Close()
	data, err := io.ReadAll(io.LimitReader(resp.Body, 4<<20))
	if err != nil {
		return ChatResponse{}, fmt.Errorf("read llm response: %w", err)
	}
	if resp.StatusCode/100 != 2 {
		return ChatResponse{}, &APIError{Status: resp.StatusCode, Message: truncate(string(data), 500)}
	}

	var r chatResult
	if err := json.Unmarshal(data, &r); err != nil {
		return ChatResponse{}, fmt.Errorf("decode llm response: %w", err)
	}
	if r.Error != nil {
		status, convErr := strconv.Atoi(strings.Trim(string(r.Error.Code), `"`))
		if convErr != nil || status == 0 {
			status = http.StatusBadGateway
		}
		return ChatResponse{}, &APIError{Status: status, Message: r.Error.Message}
	}
	if len(r.Choices) == 0 {
		return ChatResponse{}, &APIError{Status: http.StatusBadGateway, Message: "empty choices"}
	}
	msg := r.Choices[0].Message
	msg.Role = RoleAssistant
	return ChatResponse{Message: msg, Usage: r.Usage}, nil
}

func retryable(err error) bool {
	var apiErr *APIError
	if errors.As(err, &apiErr) {
		return apiErr.Status == http.StatusTooManyRequests || apiErr.Status >= 500
	}
	return !errors.Is(err, context.Canceled) // network errors and per-attempt timeouts
}

func truncate(s string, n int) string {
	if len(s) <= n {
		return s
	}
	return s[:n] + "…"
}

package agent

import (
	"context"
	"encoding/json"
	"log/slog"
	"sync"
	"time"

	"github.com/TheLastManStandin/TestForSemen/backend/internal/domain"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/expense"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/llm"
)

// History stores the conversation in chat-completions JSON.
type History interface {
	RecentChat(ctx context.Context, userID int64, since time.Time, limit int) ([]json.RawMessage, error)
	AppendChat(ctx context.Context, userID int64, msgs []json.RawMessage) error
}

// TraceSink stores one record per agent run.
type TraceSink interface {
	SaveTrace(ctx context.Context, t domain.Trace) error
}

// Config tunes the agent loop.
type Config struct {
	Model         string
	MaxIterations int           // LLM calls per message; default 6
	HistoryLimit  int           // messages; default 20
	HistoryWindow time.Duration // default 6h
	Temperature   float64
}

// Agent is safe for concurrent use; runs for the same member are serialized.
type Agent struct {
	llm     llm.Client
	svc     *expense.Service
	history History
	traces  TraceSink
	cfg     Config
	log     *slog.Logger
	locks   sync.Map // userID -> *sync.Mutex
}

// New builds an agent with defaults applied.
func New(client llm.Client, svc *expense.Service, history History, traces TraceSink, cfg Config, log *slog.Logger) *Agent {
	if cfg.MaxIterations == 0 {
		cfg.MaxIterations = 6
	}
	if cfg.HistoryLimit == 0 {
		cfg.HistoryLimit = 20
	}
	if cfg.HistoryWindow == 0 {
		cfg.HistoryWindow = 6 * time.Hour
	}
	if log == nil {
		log = slog.Default()
	}
	return &Agent{llm: client, svc: svc, history: history, traces: traces, cfg: cfg, log: log}
}

package agent

import (
	"context"
	"encoding/json"
	"sync"
	"time"

	"github.com/TheLastManStandin/TestForSemen/backend/internal/domain"
)

// MemoryStore is an in-memory History and TraceSink for tests and evals.
type MemoryStore struct {
	mu     sync.Mutex
	now    func() time.Time
	chats  map[int64][]storedMessage
	traces []domain.Trace
}

type storedMessage struct {
	at      time.Time
	content json.RawMessage
}

// NewMemoryStore uses now to timestamp messages (pass the same clock as the service).
func NewMemoryStore(now func() time.Time) *MemoryStore {
	if now == nil {
		now = time.Now
	}
	return &MemoryStore{now: now, chats: map[int64][]storedMessage{}}
}

func (s *MemoryStore) RecentChat(_ context.Context, userID int64, since time.Time, limit int) ([]json.RawMessage, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	var out []json.RawMessage
	for _, m := range s.chats[userID] {
		if !m.at.Before(since) {
			out = append(out, m.content)
		}
	}
	if limit > 0 && len(out) > limit {
		out = out[len(out)-limit:]
	}
	return out, nil
}

func (s *MemoryStore) AppendChat(_ context.Context, userID int64, msgs []json.RawMessage) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	at := s.now()
	for _, m := range msgs {
		s.chats[userID] = append(s.chats[userID], storedMessage{at: at, content: m})
	}
	return nil
}

func (s *MemoryStore) SaveTrace(_ context.Context, t domain.Trace) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	t.ID = int64(len(s.traces) + 1)
	t.CreatedAt = s.now()
	s.traces = append(s.traces, t)
	return nil
}

// flexString accepts a JSON string or number: models sometimes send 350 instead of "350".
type flexString string

func (f *flexString) UnmarshalJSON(b []byte) error {
	var s string
	if err := json.Unmarshal(b, &s); err == nil {
		*f = flexString(s)
		return nil
	}
	var n json.Number
	if err := json.Unmarshal(b, &n); err != nil {
		return errors.New("ожидается строка или число")
	}
	*f = flexString(n.String())
	return nil
}

// flexInt accepts a JSON number or a numeric string.
type flexInt int64

func (f *flexInt) UnmarshalJSON(b []byte) error {
	if string(b) == "null" {
		return nil
	}
	var s string
	if err := json.Unmarshal(b, &s); err == nil {
		v, err := strconv.ParseInt(strings.TrimSpace(s), 10, 64)
		if err != nil {
			return fmt.Errorf("ожидается целое число, получено %q", s)
		}
		*f = flexInt(v)
		return nil
	}
	var n json.Number
	if err := json.Unmarshal(b, &n); err != nil {
		return errors.New("ожидается целое число")
	}
	v, err := n.Int64()
	if err != nil {
		return fmt.Errorf("ожидается целое число, получено %s", n)
	}
	*f = flexInt(v)
	return nil
}

// argError marks malformed tool arguments.
type argError struct{ err error }

func (e *argError) Error() string {
	return "некорректные аргументы: " + e.err.Error()
}

func decodeArgs(raw []byte, v any) error {
	if len(bytes.TrimSpace(raw)) == 0 {
		raw = []byte("{}")
	}
	if err := json.Unmarshal(raw, v); err != nil {
		return &argError{err: err}
	}
	return nil
}

type rangeArgs struct {
	Period string `json:"period"`
	From   string `json:"from"`
	To     string `json:"to"`

// execute runs one tool call and returns the tool message content plus a trace step.
func (a *Agent) execute(ctx context.Context, userID int64, call llm.ToolCall) (string, domain.TraceStep) {
	start := time.Now()
	out, err := a.dispatch(ctx, userID, call.Function.Name, []byte(call.Function.Arguments))
	result := out
	if err != nil {
		if isInternal(err) {
			a.log.ErrorContext(ctx, "agent tool failed", "tool", call.Function.Name, "user_id", userID, "err", err)
		}
		result = map[string]string{"error": toolError(err)}
	}
	data, mErr := json.Marshal(result)
	if mErr != nil {
		data = []byte(`{"error":"внутренняя ошибка"}`)
	}
	args := json.RawMessage(call.Function.Arguments)
	if !json.Valid(args) {
		args, _ = json.Marshal(call.Function.Arguments)
	}
	return string(data), domain.TraceStep{Tool: call.Function.Name, Args: args, Result: data, Ms: time.Since(start).Milliseconds()}
}

func (a *Agent) dispatch(ctx context.Context, userID int64, name string, raw []byte) (any, error) {
	switch name {
	case "add_expense":
		return a.addExpense(ctx, userID, raw)
	case "find_expenses":
		return a.findExpenses(ctx, userID, raw)
	case "get_summary":
		return a.getSummary(ctx, userID, raw)
	case "update_expense":
		return a.updateExpense(ctx, userID, raw)
	case "delete_expense":
		return a.deleteExpense(ctx, userID, raw)
	}
	return nil, fmt.Errorf("%w %q", errUnknownTool, name)
}

func (a *Agent) addExpense(ctx context.Context, userID int64, raw []byte) (any, error) {

	}
	if err := decodeArgs(raw, &args); err != nil {
		return nil, err
	}
	amount, err := parseAmount(string(args.Amount))
	if err != nil {
		return nil, err
	}
	cat, err := domain.ParseCategory(args.Category)

	if args.ID <= 0 {
		return nil, domain.Invalid("id", "нужен id траты — сначала найди её через find_expenses")
	}
	var patch expense.Patch
	if args.Amount != nil {
		m, err := parseAmount(string(*args.Amount))
		if err != nil {
			return nil, err
		}
		patch.Amount = &m
	}
	if args.Category != nil {
		c, err := domain.ParseCategory(*args.Category)
		if err != nil {
			return nil, err
		}
		patch.Category = &c
	}
	if args.Date != nil {
		d, err := domain.ParseDate(*args.Date)
		if err != nil {
			return nil, err
		}
		patch.SpentAt = &d
	}
	patch.Comment = args.Comment
	if patch.Amount == nil && patch.Category == nil && patch.SpentAt == nil && patch.Comment == nil {
		return nil, domain.Invalid("fields", "не передано ни одного поля для изменения")
	}
	e, err := a.svc.Update(ctx, expense.Own(userID), int64(args.ID), patch)
	if err != nil {
		return nil, err
	}
	return map[string]any{"updated": view(e)}, nil
}

func (a *Agent) deleteExpense(ctx context.Context, userID int64, raw []byte) (any, error) {

// resolveRange turns a period or from/to into dates. With required, a missing range means
// "this month" and a half-open range is closed with 2000-01-01 or today.
func (a *Agent) resolveRange(r rangeArgs, required bool) (*time.Time, *time.Time, error) {
	if r.Period != "" {
		if r.From != "" || r.To != "" {
			return nil, nil, domain.Invalid("period", "укажи либо period, либо from/to")
		}
		from, to, err := domain.ResolvePeriod(domain.Period(r.Period), a.svc.Now())
		if err != nil {
			return nil, nil, err
		}
		return &from, &to, nil
	}
	var from, to *time.Time
	if r.From != "" {
		t, err := domain.ParseDate(r.From)
		if err != nil {
			return nil, nil, err
		}
		from = &t
	}
	if r.To != "" {
		t, err := domain.ParseDate(r.To)
		if err != nil {
			return nil, nil, err
		}
		to = &t
	}
	if required {
		if from == nil && to == nil {
			f, t, _ := domain.ResolvePeriod(domain.PeriodThisMonth, a.svc.Now())
			return &f, &t, nil
		}
		if from == nil {
			f := time.Date(2000, 1, 1, 0, 0, 0, 0, time.UTC)
			from = &f
		}
		if to == nil {
			t := a.svc.Today()
			to = &t
		}
	}
	return from, to, nil
}

		}

type History interface {
	RecentChat(ctx context.Context, userID int64, since time.Time, limit int) ([]json.RawMessage, error)
	AppendChat(ctx context.Context, userID int64, msgs []json.RawMessage) error

type TraceSink interface {
	SaveTrace(ctx context.Context, t domain.Trace) error
}

// Config tunes the agent loop.
type Config struct {
	Model         string
	MaxIterations int           // LLM calls per message; default 6
	HistoryLimit  int           // messages; default 20
	HistoryWindow time.Duration // default 6h
	Temperature   float64
}

// Source tells whether the input was typed or transcribed.
type Source string

const (
	SourceText  Source = "text"
	SourceVoice Source = "voice"

// Input is one member message.
type Input struct {
	UserID int64 // from the Telegram update, never from the model
	Text   string
	Source Source
	STTms  *int // transcription latency for voice input

	Reply string

	Usage llm.Usage

// ErrTooManySteps is recorded in the trace when the loop hits MaxIterations.
var ErrTooManySteps = errors.New("agent: too many tool iterations")

// ReplyTooManySteps is sent to the member when the loop gives up.
const ReplyTooManySteps = "Не получилось разобраться с запросом. Попробуй сформулировать иначе 🙏"

const replyEmpty = "Готово."

// Agent is safe for concurrent use; runs for the same member are serialized.
type Agent struct {
	llm     llm.Client
	svc     *expense.Service
	history History
	traces  TraceSink
	cfg     Config
	log     *slog.Logger
	locks   sync.Map // userID -> *sync.Mutex

// New builds an agent with defaults applied.
func New(client llm.Client, svc *expense.Service, history History, traces TraceSink, cfg Config, log *slog.Logger) *Agent {
	if cfg.MaxIterations == 0 {
		cfg.MaxIterations = 6
	}
	if cfg.HistoryLimit == 0 {
		cfg.HistoryLimit = 20
	}
	if cfg.HistoryWindow == 0 {
		cfg.HistoryWindow = 6 * time.Hour
	}
	if log == nil {
		log = slog.Default()
	}
	return &Agent{llm: client, svc: svc, history: history, traces: traces, cfg: cfg, log: log}
}

// Run handles one message. The error is non-nil only for infrastructure failures;
// a trace is saved in every case.
func (a *Agent) Run(ctx context.Context, in Input) (Result, error) {
	if in.Source == "" {
		in.Source = SourceText
	}
	mu := a.userLock(in.UserID)
	mu.Lock()
	defer mu.Unlock()

	start := time.Now()
	res, err := a.run(ctx, in)

	trace := domain.Trace{
		UserID: in.UserID, Source: string(in.Source), Input: in.Text, Output: res.Reply, Steps: res.Steps,
		Model: a.cfg.Model, PromptTokens: res.Usage.PromptTokens, CompletionTokens: res.Usage.CompletionTokens,
		STTms: in.STTms, LatencyMs: int(time.Since(start).Milliseconds()),
	}
	if err != nil {
		trace.Error = err.Error()
	}
	if saveErr := a.traces.SaveTrace(context.WithoutCancel(ctx), trace); saveErr != nil {
		a.log.ErrorContext(ctx, "save trace", "err", saveErr)
	}
	if errors.Is(err, ErrTooManySteps) {
		return res, nil
	}
	return res, err
}

func (a *Agent) run(ctx context.Context, in Input) (Result, error) {
	now := a.svc.Now()
	history, err := a.loadHistory(ctx, in.UserID, now)
	if err != nil {
		return Result{}, err
	}

	user := llm.Message{Role: llm.RoleUser, Content: in.Text}
	msgs := make([]llm.Message, 0, len(history)+8)
	msgs = append(msgs, llm.Message{Role: llm.RoleSystem, Content: BuildSystemPrompt(now)})
	msgs = append(msgs, history...)
	msgs = append(msgs, user)
	turn := []llm.Message{user}

	var res Result
	temperature := a.cfg.Temperature
	for range a.cfg.MaxIterations {
		resp, err := a.llm.Chat(ctx, llm.ChatRequest{Model: a.cfg.Model, Messages: msgs, Tools: toolDefs, Temperature: &temperature})
		if err != nil {
			return res, fmt.Errorf("llm: %w", err)
		}
		res.Usage.Add(resp.Usage)

		reply := resp.Message
		reply.Role = llm.RoleAssistant
		msgs = append(msgs, reply)
		turn = append(turn, reply)

		if len(reply.ToolCalls) == 0 {
			res.Reply = strings.TrimSpace(reply.Content)
			if res.Reply == "" {
				res.Reply = replyEmpty
			}
			a.saveTurn(ctx, in.UserID, turn)
			return res, nil
		}
		for _, call := range reply.ToolCalls {
			out, step := a.execute(ctx, in.UserID, call)
			res.Steps = append(res.Steps, step)
			toolMsg := llm.Message{Role: llm.RoleTool, ToolCallID: call.ID, Content: out}
			msgs = append(msgs, toolMsg)
			turn = append(turn, toolMsg)
		}
	}

	res.Reply = ReplyTooManySteps
	turn = append(turn, llm.Message{Role: llm.RoleAssistant, Content: res.Reply})
	a.saveTurn(ctx, in.UserID, turn)
	return res, ErrTooManySteps
}

// loadHistory returns recent messages starting at a user message, so a tool result
// is never sent without the assistant call that produced it.
func (a *Agent) loadHistory(ctx context.Context, userID int64, now time.Time) ([]llm.Message, error) {
	raw, err := a.history.RecentChat(ctx, userID, now.Add(-a.cfg.HistoryWindow), a.cfg.HistoryLimit)
	if err != nil {
		return nil, fmt.Errorf("load history: %w", err)
	}
	msgs := make([]llm.Message, 0, len(raw))
	for _, r := range raw {
		var m llm.Message
		if err := json.Unmarshal(r, &m); err == nil {
			msgs = append(msgs, m)
		}
	}
	for i, m := range msgs {
		if m.Role == llm.RoleUser {
			return msgs[i:], nil
		}
	}
	return nil, nil
}

func (a *Agent) saveTurn(ctx context.Context, userID int64, turn []llm.Message) {
	raw := make([]json.RawMessage, 0, len(turn))
	for _, m := range turn {
		if b, err := json.Marshal(m); err == nil {
			raw = append(raw, b)
		}
	}
	if err := a.history.AppendChat(context.WithoutCancel(ctx), userID, raw); err != nil {
		a.log.ErrorContext(ctx, "save history", "err", err)
	}
}

func (a *Agent) userLock(userID int64) *sync.Mutex {
	v, _ := a.locks.LoadOrStore(userID, &sync.Mutex{})
	return v.(*sync.Mutex)
}

// Package stt transcribes voice messages.
package stt

import (
	"bytes"
	"context"
	"encoding/base64"
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"strings"
	"time"
)

// Transcriber turns audio into text.
type Transcriber interface {
	Transcribe(ctx context.Context, audio []byte, format string) (string, error)
}

// OpenRouterConfig configures OpenRouter's /audio/transcriptions endpoint.
type OpenRouterConfig struct {
	BaseURL    string // e.g. https://openrouter.ai/api/v1
	APIKey     string
	Model      string // e.g. openai/whisper-large-v3
	Language   string // ISO-639-1, e.g. "ru"; empty = auto-detect
	Timeout    time.Duration
	HTTPClient *http.Client
}

// OpenRouter implements Transcriber.
type OpenRouter struct {
	cfg  OpenRouterConfig
	http *http.Client
}

// NewOpenRouter returns a transcriber with a 30s default timeout.
func NewOpenRouter(cfg OpenRouterConfig) *OpenRouter {
	if cfg.Timeout == 0 {
		cfg.Timeout = 30 * time.Second
	}
	hc := cfg.HTTPClient
	if hc == nil {
		hc = &http.Client{}
	}
	return &OpenRouter{cfg: cfg, http: hc}
}

type transcriptionRequest struct {
	Model      string     `json:"model"`
	Language   string     `json:"language,omitempty"`
	InputAudio inputAudio `json:"input_audio"`
}

type inputAudio struct {
	Data   string `json:"data"`   // base64, no data: prefix
	Format string `json:"format"` // ogg, wav, mp3…
}

func (c *OpenRouter) Transcribe(ctx context.Context, audio []byte, format string) (string, error) {
	body, err := json.Marshal(transcriptionRequest{
		Model: c.cfg.Model, Language: c.cfg.Language,
		InputAudio: inputAudio{Data: base64.StdEncoding.EncodeToString(audio), Format: format},
	})
	if err != nil {
		return "", fmt.Errorf("stt: marshal: %w", err)
	}

	ctx, cancel := context.WithTimeout(ctx, c.cfg.Timeout)
	defer cancel()
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, strings.TrimRight(c.cfg.BaseURL, "/")+"/audio/transcriptions", bytes.NewReader(body))
	if err != nil {
		return "", err
	}
	req.Header.Set("Authorization", "Bearer "+c.cfg.APIKey)
	req.Header.Set("Content-Type", "application/json")

	resp, err := c.http.Do(req)
	if err != nil {
		return "", fmt.Errorf("stt: request: %w", err)
	}
	defer resp.Body.Close()
	data, err := io.ReadAll(io.LimitReader(resp.Body, 1<<20))
	if err != nil {
		return "", fmt.Errorf("stt: read: %w", err)
	}
	if resp.StatusCode/100 != 2 {
		return "", fmt.Errorf("stt: status %d: %s", resp.StatusCode, strings.TrimSpace(string(data)))
	}
	var out struct {
		Text string `json:"text"`
	}
	if err := json.Unmarshal(data, &out); err != nil {
		return "", fmt.Errorf("stt: decode: %w", err)
	}
	return strings.TrimSpace(out.Text), nil
}

// Package bot routes Telegram messages from family members to the agent.
package bot

import (
	"context"
	"fmt"
	"log/slog"
	"strings"
	"time"
	"unicode/utf8"

	"github.com/TheLastManStandin/TestForSemen/backend/internal/agent"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/stt"
)

const maxMessageRunes = 4096

// Messenger is the part of Telegram the handler needs.
type Messenger interface {
	SendText(ctx context.Context, chatID int64, text string) error
	SendTyping(ctx context.Context, chatID int64) error
	DownloadFile(ctx context.Context, fileID string) ([]byte, error)
}

// AgentRunner processes one member message.
type AgentRunner interface {
	Run(ctx context.Context, in agent.Input) (agent.Result, error)
}

// MemberChecker tells whether a Telegram user belongs to the family.
type MemberChecker interface {
	MemberExists(ctx context.Context, telegramID int64) (bool, error)
}

// Incoming is a transport-independent message.
type Incoming struct {
	ChatID int64
	UserID int64
	Text   string
	Voice  *Voice
}

// Voice is a voice note attachment.
type Voice struct {
	FileID   string
	Duration int // seconds
}

// Config tunes the handler.
type Config struct {
	MaxVoiceSeconds int           // default 60
	TypingInterval  time.Duration // Telegram shows "typing" for ~5s; default 4s
	MessageTimeout  time.Duration // whole-message budget; default 2m
}

// Handler is safe for concurrent use.
type Handler struct {
	msg     Messenger
	agent   AgentRunner
	members MemberChecker
	stt     stt.Transcriber // nil disables voice
	cfg     Config
	log     *slog.Logger
}

// NewHandler applies defaults. A nil transcriber disables voice messages.
func NewHandler(msg Messenger, ag AgentRunner, members MemberChecker, transcriber stt.Transcriber, cfg Config, log *slog.Logger) *Handler {
	if cfg.MaxVoiceSeconds == 0 {
		cfg.MaxVoiceSeconds = 60
	}
	if cfg.TypingInterval == 0 {
		cfg.TypingInterval = 4 * time.Second
	}
	if cfg.MessageTimeout == 0 {
		cfg.MessageTimeout = 2 * time.Minute
	}
	if log == nil {
		log = slog.Default()
	}
	return &Handler{msg: msg, agent: ag, members: members, stt: transcriber, cfg: cfg, log: log}
}

// Handle processes one incoming message end to end.
func (h *Handler) Handle(ctx context.Context, in Incoming) {
	ctx, cancel := context.WithTimeout(ctx, h.cfg.MessageTimeout)
	defer cancel()

	ok, err := h.members.MemberExists(ctx, in.UserID)
	if err != nil {
		h.log.ErrorContext(ctx, "member check failed", "user_id", in.UserID, "err", err)
		h.reply(ctx, in.ChatID, textInternalError)
		return
	}
	if !ok {
		h.log.InfoContext(ctx, "message from non-member", "user_id", in.UserID)
		h.reply(ctx, in.ChatID, fmt.Sprintf(textNotMember, in.UserID))
		return
	}

	text := strings.TrimSpace(in.Text)
	switch {
	case in.Voice != nil:
		h.handleVoice(ctx, in)
	case text == "/start":
		h.reply(ctx, in.ChatID, textStart)
	case text != "":
		stop := h.typing(ctx, in.ChatID)
		defer stop()
		h.runAgent(ctx, in.ChatID, agent.Input{UserID: in.UserID, Text: text, Source: agent.SourceText}, "")
	default:
		h.reply(ctx, in.ChatID, textUnsupported)
	}
}

func (h *Handler) handleVoice(ctx context.Context, in Incoming) {
	if h.stt == nil {
		h.reply(ctx, in.ChatID, textVoiceDisabled)
		return
	}
	if in.Voice.Duration > h.cfg.MaxVoiceSeconds {
		h.reply(ctx, in.ChatID, fmt.Sprintf(textVoiceTooLong, h.cfg.MaxVoiceSeconds))
		return
	}
	stop := h.typing(ctx, in.ChatID)
	defer stop()

	audio, err := h.msg.DownloadFile(ctx, in.Voice.FileID)
	if err != nil {
		h.log.ErrorContext(ctx, "voice download failed", "user_id", in.UserID, "err", err)
		h.reply(ctx, in.ChatID, textVoiceFailed)
		return
	}
	start := time.Now()
	text, err := h.stt.Transcribe(ctx, audio, "ogg")
	sttMs := int(time.Since(start).Milliseconds())
	text = strings.TrimSpace(text)
	if err != nil || text == "" {
		h.log.WarnContext(ctx, "voice transcription failed", "user_id", in.UserID, "err", err)
		h.reply(ctx, in.ChatID, textVoiceFailed)
		return
	}
	h.runAgent(ctx, in.ChatID, agent.Input{UserID: in.UserID, Text: text, Source: agent.SourceVoice, STTms: &sttMs}, "🎤 «"+text+"»\n\n")
}

func (h *Handler) runAgent(ctx context.Context, chatID int64, in agent.Input, prefix string) {
	res, err := h.agent.Run(ctx, in)
	if err != nil {
		h.log.ErrorContext(ctx, "agent failed", "user_id", in.UserID, "err", err)
		h.reply(ctx, chatID, prefix+textInternalError)
		return
	}
	h.reply(ctx, chatID, prefix+res.Reply)
}

func (h *Handler) reply(ctx context.Context, chatID int64, text string) {
	if utf8.RuneCountInString(text) > maxMessageRunes {
		text = string([]rune(text)[:maxMessageRunes-1]) + "…"
	}
	if err := h.msg.SendText(ctx, chatID, text); err != nil {
		h.log.ErrorContext(ctx, "send message failed", "chat_id", chatID, "err", err)
	}
}

// typing shows the "typing…" status until the returned stop func is called.
func (h *Handler) typing(ctx context.Context, chatID int64) func() {
	ctx, cancel := context.WithCancel(ctx)
	done := make(chan struct{})
	go func() {
		defer close(done)
		ticker := time.NewTicker(h.cfg.TypingInterval)
		defer ticker.Stop()
		for {
			if err := h.msg.SendTyping(ctx, chatID); err != nil && ctx.Err() == nil {
				h.log.DebugContext(ctx, "send typing failed", "err", err)
			}
			select {
			case <-ctx.Done():
				return
			case <-ticker.C:
			}
		}
	}()
	return func() {
		cancel()
		<-done
	}
}

package bot

import (
	"context"
	"fmt"
	"io"
	"log/slog"
	"net/http"
	"time"

	tgbot "github.com/go-telegram/bot"
	"github.com/go-telegram/bot/models"
)

const maxFileBytes = 20 << 20 // Telegram bot API download limit

// Telegram adapts go-telegram/bot to Messenger and feeds updates to a Handler.
type Telegram struct {
	b       *tgbot.Bot
	http    *http.Client
	handler *Handler
	log     *slog.Logger
}

// NewTelegram creates the client; it calls getMe, so an invalid token fails fast.
func NewTelegram(token string, log *slog.Logger) (*Telegram, error) {
	t := &Telegram{http: &http.Client{Timeout: 60 * time.Second}, log: log}
	b, err := tgbot.New(token, tgbot.WithDefaultHandler(t.onUpdate))
	if err != nil {
		return nil, fmt.Errorf("telegram: %w", err)
	}
	t.b = b
	return t, nil
}

// SetHandler must be called before Start.
func (t *Telegram) SetHandler(h *Handler) { t.handler = h }

// Start long-polls until ctx is cancelled. Updates are handled concurrently.
func (t *Telegram) Start(ctx context.Context) { t.b.Start(ctx) }

func (t *Telegram) onUpdate(ctx context.Context, _ *tgbot.Bot, u *models.Update) {
	in, ok := toIncoming(u)
	if !ok || t.handler == nil {
		return
	}
	t.handler.Handle(ctx, in)
}

func toIncoming(u *models.Update) (Incoming, bool) {
	if u == nil || u.Message == nil || u.Message.From == nil {
		return Incoming{}, false
	}
	m := u.Message
	in := Incoming{ChatID: m.Chat.ID, UserID: m.From.ID, Text: m.Text}
	if m.Voice != nil {
		in.Voice = &Voice{FileID: m.Voice.FileID, Duration: m.Voice.Duration}
	}
	return in, true
}

func (t *Telegram) SendText(ctx context.Context, chatID int64, text string) error {
	_, err := t.b.SendMessage(ctx, &tgbot.SendMessageParams{ChatID: chatID, Text: text})
	return err
}

func (t *Telegram) SendTyping(ctx context.Context, chatID int64) error {
	_, err := t.b.SendChatAction(ctx, &tgbot.SendChatActionParams{ChatID: chatID, Action: models.ChatActionTyping})
	return err
}

func (t *Telegram) DownloadFile(ctx context.Context, fileID string) ([]byte, error) {
	f, err := t.b.GetFile(ctx, &tgbot.GetFileParams{FileID: fileID})
	if err != nil {
		return nil, fmt.Errorf("get file: %w", err)
	}
	req, err := http.NewRequestWithContext(ctx, http.MethodGet, t.b.FileDownloadLink(f), nil)
	if err != nil {
		return nil, err
	}
	resp, err := t.http.Do(req)
	if err != nil {
		return nil, fmt.Errorf("download file: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode != http.StatusOK {
		return nil, fmt.Errorf("download file: status %d", resp.StatusCode)
	}
	data, err := io.ReadAll(io.LimitReader(resp.Body, maxFileBytes+1))
	if err != nil {
		return nil, fmt.Errorf("read file: %w", err)
	}
	if len(data) > maxFileBytes {
		return nil, fmt.Errorf("file larger than %d bytes", maxFileBytes)
	}
	return data, nil
}

var _ Messenger = (*Telegram)(nil)

func Demo(ctx context.Context, svc *expense.Service, members []domain.Member, days int, rnd *rand.Rand) (int, error) {

		if err != nil {
			return fmt.Errorf("seed %q: %w", comment, err)
		}
		n++
		return nil
	}

	for offset := days - 1; offset >= 0; offset-- {
		date := svc.Today().AddDate(0, 0, -offset)
		head := members[0].TelegramID
		if date.Day() == 5 {
			if err := add(head, 45000, domain.CategoryHousing, "аренда", offset); err != nil {
				return n, err
			}
		}
		if date.Day() == 20 {
			if err := add(head, 6500, domain.CategoryHousing, "коммуналка", offset); err != nil {
				return n, err
			}
		}
		for _, m := range members {
			for range rnd.IntN(3) {
				t := daily[rnd.IntN(len(daily))]
				rub := (t.min + rnd.IntN(t.max-t.min+1)) / 10 * 10
				if err := add(m.TelegramID, max(rub, 10), t.category, t.comment, offset); err != nil {
					return n, err
				}
			}
		}
	}
	return n, nil
}
```

package main

	"github.com/TheLastManStandin/TestForSemen/backend/internal/config"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/events"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/expense"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/httpapi"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/llm"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/seed"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/store/postgres"
	"github.com/TheLastManStandin/TestForSemen/backend/internal/stt"
)

func main() {
	if err := run(); err != nil {
		slog.Error("fatal", "err", err)
		os.Exit(1)
	}
}

func run() error {
	cfg, err := config.Load()
	if err != nil {
		return err
	}
	log := newLogger(cfg.LogLevel)
	slog.SetDefault(log)

	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()

	pool, err := postgres.Open(ctx, cfg.DatabaseURL)
	if err != nil {
		return err
	}
	defer pool.Close()
	if err := postgres.Migrate(ctx, pool); err != nil {
		return err
	}
	store := postgres.New(pool)

	bus := events.NewBus()
	svc := expense.NewService(store, bus, cfg.Location, time.Now)
	if err := svc.SyncMembers(ctx, cfg.Members); err != nil {
		return fmt.Errorf("sync members: %w", err)
	}
	if cfg.SeedDemo {
		n, err := seed.Demo(ctx, svc, cfg.Members, 60, rand.New(rand.NewPCG(uint64(time.Now().UnixNano()), 42)))
		if err != nil {
			return fmt.Errorf("seed demo data: %w", err)
		}
		log.Info("demo data seeded", "expenses", n)
	}

	llmClient := llm.NewOpenAI(llm.OpenAIConfig{
		BaseURL: cfg.LLMBaseURL, APIKey: cfg.LLMAPIKey, Timeout: cfg.LLMTimeout, MaxRetries: 2,
		Referer: "https://github.com/TheLastManStandin/TestForSemen", Title: "Family Expenses Bot",
	})
	ag := agent.New(llmClient, svc, store, store, agent.Config{Model: cfg.LLMModel, Temperature: 0.1}, log)

	var transcriber stt.Transcriber
	if cfg.STTEnabled {
		transcriber = stt.NewOpenRouter(stt.OpenRouterConfig{
			BaseURL: cfg.LLMBaseURL, APIKey: cfg.LLMAPIKey, Model: cfg.STTModel, Language: "ru", Timeout: cfg.LLMTimeout,
		})
	}

	tg, err := bot.NewTelegram(cfg.TelegramToken, log)
	if err != nil {
		return err
	}
	tg.SetHandler(bot.NewHandler(tg, ag, svc, transcriber, bot.Config{MaxVoiceSeconds: cfg.STTMaxSeconds}, log))

	g, gctx := errgroup.WithContext(ctx)
	srv := &http.Server{
		Addr:              cfg.HTTPAddr,
		Handler:           httpapi.NewHandler(httpapi.Deps{Service: svc, Traces: store, Bus: bus, Health: pool.Ping, Log: log}),
		ReadHeaderTimeout: 10 * time.Second,
		// No WriteTimeout: it would cut long-lived SSE connections.
		// BaseContext ends SSE streams on shutdown instead of waiting for the timeout.
		BaseContext: func(net.Listener) context.Context { return gctx },
	}

	g.Go(func() error {
		log.Info("http server listening", "addr", cfg.HTTPAddr)
		if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
			return err
		}
		return nil
	})
	g.Go(func() error {
		log.Info("telegram bot polling")
		tg.Start(gctx)
		return nil
	})
	g.Go(func() error {
		<-gctx.Done()
		shutdownCtx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
		defer cancel()
		return srv.Shutdown(shutdownCtx)
	})
	return g.Wait()
}

func newLogger(level string) *slog.Logger {
	var lvl slog.Level
	if err := lvl.UnmarshalText([]byte(level)); err != nil {
		lvl = slog.LevelInfo
	}
	return slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: lvl}))
}
