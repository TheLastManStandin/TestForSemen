## Global Constraints (apply to every plan)

- Go module path: `github.com/TheLastManStandin/TestForSemen/backend` (module root `backend/`).
- Go `1.26` (`go 1.26` in `go.mod`; goose v3.29 requires it). Docker build image `golang:1.26-alpine`.
- Pinned Go deps: `github.com/go-telegram/bot v1.27.0`, `github.com/jackc/pgx/v5 v5.11.0`, `github.com/pressly/goose/v3 v3.29.0`, `github.com/oapi-codegen/oapi-codegen/v2 v2.8.0` (as `go tool`), `github.com/oapi-codegen/runtime v1.7.0`, `github.com/testcontainers/testcontainers-go v0.44.0` (+ `modules/postgres`), `github.com/caarlos0/env/v11 v11.4.1`, `github.com/stretchr/testify v1.12.1`, `gopkg.in/yaml.v3 v3.0.1`, `golang.org/x/sync` (errgroup).
- sqlc `1.31.1` runs via Docker image `sqlc/sqlc:1.31.1` (`make gen-sql`). Generated code is committed.
- Postgres image `postgres:16` (Debian/glibc — needed for case-insensitive Cyrillic `ILIKE`), both in compose and testcontainers.
- Money is `int64` kopecks (`domain.Money`). API `amount` is a decimal string with a dot: `"350.00"`. User-facing format: `"1 200 ₽"`, `"1 200,50 ₽"`.
- Category codes: `food, transport, housing, entertainment, health, shopping, other`; Russian names: еда, транспорт, жильё, развлечения, здоровье, покупки, другое.
- Dates in the domain are `time.Time` at 00:00 UTC of the calendar day (`domain.DateOf`). "Today" is computed in `APP_TIMEZONE` (default `Europe/Moscow`).
- Access rule: a member's own scope returns `domain.ErrNotFound` for other members' expenses (never "forbidden").
- Agent tool JSON schemas never contain `user_id`; it comes from the Telegram update.
- User-facing texts (bot replies, UI, validation messages) are Russian; code identifiers and comments are English.
- Commits: Conventional Commits (`feat(scope): …`, `test(scope): …`, `chore: …`, `docs: …`). No attribution trailers.
- Integration tests use testcontainers and are skipped with `go test -short`.
