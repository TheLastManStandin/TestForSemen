# Web Panel Implementation Plan (Plan 3 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A React panel for the head of the family: filterable expense list with CRUD, KPI cards, charts, live updates from the bot via SSE, and an agent journal — served by nginx inside `docker compose`.

**Architecture:** Vite + React 19 + TypeScript SPA. Types come from `api/openapi.yaml` via openapi-typescript; requests go through `openapi-fetch` and TanStack Query. Filter state lives in the URL. An `EventSource` on `/api/events` invalidates queries and shows toasts. Pure logic (money/date formatting, period presets, URL state) is unit-tested with Vitest; UI is shadcn/ui (generated by its CLI) + Recharts.

**Tech Stack:** Node 24, Vite 8.3.4, React 19.3.1, TypeScript 5.9.3, TanStack Query 5.104.3, openapi-fetch 0.17.0, openapi-typescript 7.13.0, Tailwind 4.3.3, shadcn CLI 4.21.5 (radix base, nova preset), Recharts 3.10.1, react-hook-form 7.90.0 + zod 4.6.7, sonner, next-themes, Vitest 5.0.5, ESLint 10, nginx 1.29.

**Spec:** `docs/superpowers/specs/2026-10-15-family-expenses-design.md` (section 9). Requires Plan 1 (REST API) and Plan 2 Task 9 (`docker-compose.yml`).

## Global Constraints

- The REST contract is `api/openapi.yaml`; never hand-write API types — regenerate with `npm run gen:api` (or `make gen-web`).
- Money arrives as decimal strings (`"1200.50"`); format as `1 200,50 ₽` with a no-break space (`\u00a0`) as the thousands separator and before `₽`. Never use floats for sums — convert to integer kopecks first.
- Category codes `food, transport, housing, entertainment, health, shopping, other` ↔ Еда, Транспорт, Жильё, Развлечения, Здоровье, Покупки, Другое.
- All UI text is Russian. Dates display as `14 окт` (current year) or `14 окт 2025`.
- Filter state (period, from, to, member, category, page, tab) lives in the URL query string.
- Charts follow the dataviz rules: categories → one-hue horizontal bars (7 classes is too many for a donut); per-day bars → stacked by member with categorical slots in fixed order (`--series-1..4`: light `#2a78d6 #eb6834 #1baf7a #eda100`, dark `#3987e5 #d95926 #199e70 #c98500`), legend present, tooltip on hover, text in ink colors (never series colors). Member color follows the member's position in `/api/members` (stable), never rank.
- Radix `SelectItem` cannot have `value=""` — use `"all"` as the "no filter" sentinel.
- Conventional Commits, no attribution trailers.

## Review Focus

1. **Comma decimals and spaces in the amount field** (`"1 200,50"`) — must save 1200.50, not fail or save 1200. Pinned by `normalizeAmount` tests (Task 2) used by the form (Task 5).
2. **Hand-edited or stale URLs** (`?period=foo&member=abc&page=-3`) — must fall back to defaults, never crash or send garbage to the API. Pinned by `parseFilters` fallback tests (Task 2).
3. **Changing a filter while on page 3** — must reset to page 1, otherwise the user sees an empty page. Pinned by the `applyPatch` test (Task 2).
4. **Server validation errors** (422 with `errors[].field`) — must show next to the field, not only as a generic toast. Pinned by `fieldErrors` tests (Task 3) and wired in the form (Task 5).
5. **SSE drops (laptop sleep, nginx restart)** — the panel must reconnect and refetch, and show the "offline" state meanwhile. Handled by `EventSource` auto-reconnect + refetch on `open` (Task 6); verified manually in Task 8 by restarting the backend container.

```ts
export const CATEGORY_CODES = ["food", "transport", "housing", "entertainment", "health", "shopping", "other"] as const;

export type CategoryCode = (typeof CATEGORY_CODES)[number];

export const CATEGORY_LABELS: Record<CategoryCode, string> = {
  food: "Еда",
  transport: "Транспорт",
  housing: "Жильё",
  entertainment: "Развлечения",
  health: "Здоровье",
  shopping: "Покупки",
  other: "Другое",
};

export function isCategory(v: unknown): v is CategoryCode {
  return typeof v === "string" && (CATEGORY_CODES as readonly string[]).includes(v);
}

const NBSP = "\u00a0";

/** "1200.50" -> 120050. API amounts are decimal strings; never parse them as floats. */
export function toKopecks(amount: string): number {
  const [whole, frac = ""] = amount.trim().split(".");
  return Number(whole) * 100 + Number((frac + "00").slice(0, 2));
}

/** 120050 -> "1 200,50 ₽" (no-break spaces). */
export function formatKopecks(kopecks: number): string {
  const abs = Math.abs(Math.round(kopecks));
  const whole = Math.floor(abs / 100)
    .toString()
    .replace(/\B(?=(\d{3})+(?!\d))/g, NBSP);
  const kop = abs % 100;
  const sign = kopecks < 0 ? "−" : "";
  return `${sign}${whole}${kop ? "," + String(kop).padStart(2, "0") : ""}${NBSP}₽`;
}

export function formatMoney(amount: string): string {
  return formatKopecks(toKopecks(amount));
}

/** User input "1 200,50" -> "1200.50" for the API; null if not a positive amount. */
export function normalizeAmount(input: string): string | null {
  const clean = input.replace(/[\s\u00a0]/g, "").replace(",", ".");
  if (!/^\d{1,13}(\.\d{1,2})?$/.test(clean)) return null;
  return Number(clean) > 0 ? clean : null;
}

const MONTHS = ["янв", "фев", "мар", "апр", "мая", "июн", "июл", "авг", "сен", "окт", "ноя", "дек"];

/** "2026-10-14" -> "14 окт" (or "14 окт 2025" for another year). */
export function formatDate(iso: string, todayIso: string): string {
  const [y, m, d] = iso.split("-").map(Number);
  const base = `${d} ${MONTHS[m - 1]}`;
  return iso.slice(0, 4) === todayIso.slice(0, 4) ? base : `${base} ${y}`;
}

/** "2026-10-04" -> "04.10" for chart axes. */
export function formatShortDate(iso: string): string {
  return `${iso.slice(8, 10)}.${iso.slice(5, 7)}`;
}

/** RFC 3339 timestamp -> "15 окт, 12:30" in the browser's time zone. */
export function formatDateTime(iso: string): string {
  const d = new Date(iso);
  const hh = String(d.getHours()).padStart(2, "0");
  const mm = String(d.getMinutes()).padStart(2, "0");
  return `${d.getDate()} ${MONTHS[d.getMonth()]}, ${hh}:${mm}`;
}

export function percentChange(current: number, previous: number): number | null {
  if (previous === 0) return null;
```

```ts
export type Preset = "this_week" | "this_month" | "last_month" | "last_30_days" | "custom";

export const PRESETS: { value: Preset; label: string }[] = [
  { value: "this_week", label: "Эта неделя" },
  { value: "this_month", label: "Этот месяц" },
  { value: "last_month", label: "Прошлый месяц" },
  { value: "last_30_days", label: "30 дней" },
  { value: "custom", label: "Свой период" },
];

const DAY_MS = 86_400_000;

/** Local calendar date as "YYYY-MM-DD". */
export function toISODate(d: Date): string {
  const m = String(d.getMonth() + 1).padStart(2, "0");
  const day = String(d.getDate()).padStart(2, "0");
  return `${d.getFullYear()}-${m}-${day}`;
}

export function todayISO(now: Date = new Date()): string {
  return toISODate(now);
}

function utc(iso: string): Date {
  return new Date(`${iso}T00:00:00Z`);
}

export function addDays(iso: string, n: number): string {
  return new Date(utc(iso).getTime() + n * DAY_MS).toISOString().slice(0, 10);
}

export function presetRange(p: Exclude<Preset, "custom">, todayIso: string): { from: string; to: string } {
  const firstOfMonth = `${todayIso.slice(0, 8)}01`;
  switch (p) {
    case "this_week": {
      const sinceMonday = (utc(todayIso).getUTCDay() + 6) % 7;
      return { from: addDays(todayIso, -sinceMonday), to: todayIso };
    }
    case "this_month":
      return { from: firstOfMonth, to: todayIso };
    case "last_month": {
      const lastOfPrev = addDays(firstOfMonth, -1);
      return { from: `${lastOfPrev.slice(0, 8)}01`, to: lastOfPrev };
    }
    case "last_30_days":
      return { from: addDays(todayIso, -29), to: todayIso };
  }
}

export function daysInclusive(from: string, to: string): number {
  return Math.round((utc(to).getTime() - utc(from).getTime()) / DAY_MS) + 1;
}

export function eachDay(from: string, to: string): string[] {
  const days: string[] = [];
  for (let d = from; d <= to; d = addDays(d, 1)) days.push(d);
  return days;
}
```

```ts
import { isCategory, type CategoryCode } from "./format";
import { presetRange, type Preset } from "./period";

export type Tab = "expenses" | "traces";

export interface Filters {
  preset: Preset;
  from: string;
  to: string;
  memberId: number | null;
  category: CategoryCode | null;
  page: number;
  tab: Tab;
}

const PRESET_VALUES: Preset[] = ["this_week", "this_month", "last_month", "last_30_days", "custom"];
const DEFAULT_PRESET = "this_month";
const ISO_DATE = /^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$/;

function defaults(todayIso: string): Filters {
  return { preset: DEFAULT_PRESET, ...presetRange(DEFAULT_PRESET, todayIso), memberId: null, category: null, page: 1, tab: "expenses" };
}

/** Parses the URL query; anything invalid falls back to its default. */
export function parseFilters(search: string, todayIso: string): Filters {
  const p = new URLSearchParams(search);
  const f = defaults(todayIso);

  const preset = p.get("period");
  if (preset && (PRESET_VALUES as string[]).includes(preset)) {
    if (preset === "custom") {
      const from = p.get("from") ?? "";
      const to = p.get("to") ?? "";
      if (ISO_DATE.test(from) && ISO_DATE.test(to) && from <= to) {
        Object.assign(f, { preset: "custom", from, to });
      }
    } else {
      Object.assign(f, { preset, ...presetRange(preset as Exclude<Preset, "custom">, todayIso) });
    }
  }

  const member = Number(p.get("member"));
  if (Number.isSafeInteger(member) && member > 0) f.memberId = member;

  const category = p.get("category");
  if (isCategory(category)) f.category = category;

  const page = Number(p.get("page"));
  if (Number.isInteger(page) && page > 1) f.page = page;

  if (p.get("tab") === "traces") f.tab = "traces";
  return f;
}

/** Serializes only non-default values, so the default view has a clean URL. */
export function serializeFilters(f: Filters): string {
  const p = new URLSearchParams();
  if (f.preset !== DEFAULT_PRESET) p.set("period", f.preset);
  if (f.preset === "custom") {
    p.set("from", f.from);
    p.set("to", f.to);
  }
  if (f.memberId !== null) p.set("member", String(f.memberId));
  if (f.category !== null) p.set("category", f.category);
  if (f.page > 1) p.set("page", String(f.page));
  if (f.tab !== "expenses") p.set("tab", f.tab);
  return p.toString();
}

/** Applies a UI change: presets recompute dates, edited dates mean "custom", filter changes reset the page. */
export function applyPatch(f: Filters, patch: Partial<Filters>, todayIso: string): Filters {
  const next = { ...f, ...patch };
  if (patch.preset && patch.preset !== "custom") {
    Object.assign(next, presetRange(patch.preset, todayIso));
  }
  if ((patch.from !== undefined || patch.to !== undefined) && patch.preset === undefined) {
    next.preset = "custom";
  }
  const filterKeys: (keyof Filters)[] = ["preset", "from", "to", "memberId", "category"];
  if (filterKeys.some((k) => k in patch) && !("page" in patch)) {
    next.page = 1;
  }
  return next;
}
```

```ts
type Schemas = components["schemas"];
export type Category = Schemas["Category"];

export interface ExpenseEvent {
  type: "expense.created" | "expense.updated" | "expense.deleted";
  expense: Expense;
}

export class ApiError extends Error {
  readonly status: number;
  readonly problem?: Problem;

  constructor(status: number, problem?: Problem) {
    super(problem?.errors?.[0]?.message ?? problem?.detail ?? problem?.title ?? `HTTP ${status}`);
    this.status = status;
    this.problem = problem;
  }
}

/** Resolves an openapi-fetch call to its data or throws ApiError. */
export async function unwrap<T>(call: Promise<{ data?: T; error?: unknown; response: Response }>): Promise<T> {
  const { data, error, response } = await call;
  if (error !== undefined || !response.ok) {
    throw new ApiError(response.status, error as Problem | undefined);
  }
  return data as T;
}

/** Field -> message map from a 422 problem (empty for other errors). */
export function fieldErrors(err: unknown): Record<string, string> {
  if (!(err instanceof ApiError) || !err.problem?.errors) return {};
  return Object.fromEntries(err.problem.errors.map((e) => [e.field, e.message]));
}
```

```ts
import { useCallback, useEffect, useState } from "react";
import { applyPatch, parseFilters, serializeFilters, type Filters } from "@/lib/filters";
import { todayISO } from "@/lib/period";

/** Filter state mirrored in the URL query string. */
export function useFilters(): [Filters, (patch: Partial<Filters>) => void] {
  const [filters, setFilters] = useState(() => parseFilters(window.location.search, todayISO()));

  useEffect(() => {
    const onPop = () => setFilters(parseFilters(window.location.search, todayISO()));
    window.addEventListener("popstate", onPop);
    return () => window.removeEventListener("popstate", onPop);
  }, []);

  const update = useCallback(
    (patch: Partial<Filters>) => {
      const next = applyPatch(filters, patch, todayISO());
      const qs = serializeFilters(next);
      window.history.replaceState(null, "", qs ? `?${qs}` : window.location.pathname);
      setFilters(next);
    },
    [filters],
  );

  return [filters, update];
}
```

```ts
import { useQueryClient } from "@tanstack/react-query";
import { useEffect, useRef, useState } from "react";
import type { ExpenseEvent } from "@/api/client";

const EVENT_TYPES: ExpenseEvent["type"][] = ["expense.created", "expense.updated", "expense.deleted"];

/**
 * Subscribes to /api/events. EventSource reconnects by itself; on every (re)connect we
 * refetch everything, so changes made while offline are never missed.
 */
export function useLiveUpdates(onEvent: (e: ExpenseEvent) => void): boolean {
  const qc = useQueryClient();
  const [connected, setConnected] = useState(false);
  const handler = useRef(onEvent);

  useEffect(() => {
    handler.current = onEvent;
  }, [onEvent]);

  useEffect(() => {
    const source = new EventSource("/api/events");
    const onMessage = (msg: MessageEvent<string>) => {
      const event = JSON.parse(msg.data) as ExpenseEvent;
      void qc.invalidateQueries({ queryKey: ["expenses"] });
      void qc.invalidateQueries({ queryKey: ["stats"] });
      void qc.invalidateQueries({ queryKey: ["traces"] });
      handler.current(event);
    };
    EVENT_TYPES.forEach((t) => source.addEventListener(t, onMessage));
    source.onopen = () => {
      setConnected(true);
      void qc.invalidateQueries();
    };
    source.onerror = () => setConnected(false);
    return () => source.close();
  }, [qc]);

  return connected;
}
```

```tsx
import { TrendingDown, TrendingUp } from "lucide-react";
import type { Stats } from "@/api/client";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { Skeleton } from "@/components/ui/skeleton";
import { formatKopecks, formatMoney, percentChange, toKopecks } from "@/lib/format";

interface Props {
  stats?: Stats;
  isLoading: boolean;
  days: number;
}

function Kpi({ title, value, hint, loading }: { title: string; value: React.ReactNode; hint?: React.ReactNode; loading: boolean }) {
  return (
    <Card>
      <CardHeader>
        <CardTitle className="text-sm font-normal text-muted-foreground">{title}</CardTitle>
      </CardHeader>
      <CardContent>
        {loading ? <Skeleton className="h-8 w-32" /> : <div className="text-2xl font-semibold tabular-nums">{value}</div>}
        {hint && !loading && <div className="mt-1 text-xs text-muted-foreground">{hint}</div>}
      </CardContent>
    </Card>
  );
}

export function KpiCards({ stats, isLoading, days }: Props) {
  const total = stats ? toKopecks(stats.total) : 0;
  const prev = stats ? toKopecks(stats.prev_total) : 0;
  const change = percentChange(total, prev);
  const loading = isLoading || !stats;

  let changeValue: React.ReactNode = "—";
  if (change !== null) {
    const up = change > 0;
    const Icon = up ? TrendingUp : TrendingDown;
    changeValue = (
      <span className={`inline-flex items-center gap-1.5 ${up ? "text-destructive" : "text-[var(--series-3)]"}`}>
        <Icon className="size-5" aria-hidden />
        {up ? "+" : ""}
        {change}%<span className="sr-only">{up ? " больше" : " меньше"}, чем в прошлом периоде</span>
      </span>
    );
  }

  return (
    <div className="grid grid-cols-2 gap-4 lg:grid-cols-4">
      <Kpi title="Потрачено" value={stats && formatMoney(stats.total)} loading={loading} />
      <Kpi title="Трат" value={stats?.count} loading={loading} />
      <Kpi title="В среднем в день" value={formatKopecks(total / Math.max(days, 1))} hint={`за ${days} дн.`} loading={loading} />
      <Kpi title="К прошлому периоду" value={changeValue} hint={stats && `было ${formatMoney(stats.prev_total)}`} loading={loading} />
    </div>
  );
}
```

```tsx
import { Bar, BarChart, CartesianGrid, LabelList, Legend, ResponsiveContainer, Tooltip, XAxis, YAxis } from "recharts";
import type { Member, Stats } from "@/api/client";
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card";
import { CATEGORY_LABELS, formatKopecks, formatShortDate, toKopecks } from "@/lib/format";
import { eachDay } from "@/lib/period";
import { memberColor } from "./memberColors";

interface Props {
  stats?: Stats;
  members: Member[];
  from: string;
  to: string;
}

const tick = { fill: "var(--muted-foreground)", fontSize: 12 };
const tooltipStyle = {
  background: "var(--popover)",
  border: "1px solid var(--border)",
  borderRadius: 8,
  color: "var(--popover-foreground)",
};

function compactRub(rub: number): string {
  return rub >= 1000 ? `${Math.round(rub / 100) / 10}k` : String(rub);
}

export function Charts({ stats, members, from, to }: Props) {
  if (!stats || stats.count === 0) return null;

  const byCategory = stats.by_category.map((c) => ({ label: CATEGORY_LABELS[c.category], kopecks: toKopecks(c.total) }));

  const activeMembers = members.filter((m) => stats.by_member.some((b) => b.user_id === m.telegram_id));
  const totals = new Map(stats.by_day.map((d) => [`${d.date}|${d.user_id}`, toKopecks(d.total)]));
  const byDay = eachDay(from, to).map((day) => {
    const row: Record<string, string | number> = { day: formatShortDate(day) };
    for (const m of activeMembers) row[String(m.telegram_id)] = (totals.get(`${day}|${m.telegram_id}`) ?? 0) / 100;
    return row;
  });

  return (
    <div className="grid gap-4 lg:grid-cols-5">
      <Card className="lg:col-span-2">
        <CardHeader>
          <CardTitle>По категориям</CardTitle>
        </CardHeader>
        <CardContent>
          <ResponsiveContainer width="100%" height={byCategory.length * 36 + 8}>
            <BarChart data={byCategory} layout="vertical" margin={{ left: 0, right: 96 }}>
              <XAxis type="number" hide />
              <YAxis type="category" dataKey="label" width={100} tick={tick} axisLine={false} tickLine={false} />
              <Tooltip cursor={{ fill: "var(--muted)" }} contentStyle={tooltipStyle} formatter={(v) => [formatKopecks(Number(v)), "Сумма"]} />
              <Bar dataKey="kopecks" fill="var(--chart-bar)" radius={[0, 4, 4, 0]} barSize={18}>
                <LabelList dataKey="kopecks" position="right" fill="var(--foreground)" fontSize={12} formatter={(v) => formatKopecks(Number(v))} />
              </Bar>
            </BarChart>
          </ResponsiveContainer>
        </CardContent>
      </Card>

      <Card className="lg:col-span-3">
        <CardHeader>
          <CardTitle>По дням</CardTitle>
        </CardHeader>
        <CardContent>
          <ResponsiveContainer width="100%" height={260}>
            <BarChart data={byDay} margin={{ left: 0, right: 8 }}>
              <CartesianGrid vertical={false} stroke="var(--border)" />
              <XAxis dataKey="day" tick={tick} axisLine={false} tickLine={false} minTickGap={16} />
```
