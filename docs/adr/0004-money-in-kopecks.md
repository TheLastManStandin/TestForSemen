# ADR 0004: Деньги — целые копейки

- Статус: принято
- Дата: 2026-10-15

## Решение
В домене и БД сумма — `int64` копеек (`domain.Money`). В API — десятичная строка `"1200.50"`, фронтенд переводит её в копейки без float. Парсер принимает «1 200,50», «350.5», «1 200 ₽».

## Последствия
Нет ошибок округления в суммах и агрегатах; формат в API однозначен для любого клиента. Графики используют деление на 100 только для отображения.
