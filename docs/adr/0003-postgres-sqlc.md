# ADR 0003: PostgreSQL + sqlc, без ORM

- Статус: принято
- Дата: 2026-10-15

## Контекст
Нужны фильтры по члену семьи, периоду, категории, поиск по комментарию и агрегаты для графиков. ТЗ требует запуск «со всеми зависимостями» через docker compose.

## Решение
PostgreSQL 16 (образ на Debian — регистронезависимый `ILIKE` для кириллицы), запросы на SQL, типобезопасный код генерирует sqlc, миграции — goose (встроены в бинарь). Хранилище спрятано за интерфейсом `expense.Repository`; in-memory реализация для тестов и evals проходит тот же контрактный набор тестов, что и Postgres. `Update` и `Delete` принимают владельца и фильтруют по нему прямо в SQL, поэтому изоляция не зависит от порядка «проверил, затем изменил».

## Последствия
- SQL виден явно, ошибки в запросах ловит компилятор.
- Контрактные тесты гарантируют, что in-memory и Postgres ведут себя одинаково (включая кириллицу и экранирование `%`).
